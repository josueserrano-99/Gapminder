# Gapminder
## Project contents

- `src/week5_arrays_plotting.py` contains the complete Python solution with comments.
- `data/` contains the two Gapminder CSV files used by the script.
- `output/` contains the two plots generated by the code.
- `docs/Week 5 Assignment.docx` contains the completed Word assignment.

## Requirements

- Python 3.10 or newer
- NumPy
- pandas
- matplotlib

Install the required packages from the repository folder:

```bash
python -m pip install -r requirements.txt
```

## Run the project

```bash
python src/week5_arrays_plotting.py
```

The script prints every element of the three-dimensional NumPy array and saves both requested charts in the `output` folder.
